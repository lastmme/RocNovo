# Pretrained weights

RocNovo 1.0.0 weights are hosted in our ModelScope model repository. [Open the repository](https://modelscope.cn/models/lastmme/RocNovo).

For checkpoint selection, matching configurations, and download instructions, consult the model repository's README. [Benchmark results](results.md) remain in this source repository.

The model repository includes the version 1.0.0 source package and dependencies alongside the checkpoints. See its README for installation and inference.
